Amazon Clone

A frontend recreation of the Amazon homepage built from scratch using HTML and CSS.

🚀 About the Project

I built this project to practice my HTML and CSS skills by recreating the layout and visual structure of Amazon's homepage.

The entire clone was built by me from scratch, without using AI to write the code.

🛠️ Technologies Used

- HTML5
- CSS3

✨ Features

- Amazon-style navigation bar
- Search section
- Hero/banner section
- Category cards
- Product cards and grids
- Amazon-inspired layout and styling
